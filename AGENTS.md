# Repository agent instructions

Codex is the only supported coding-agent client for this repository. This file is the
instruction authority for all repository work.

Canonical deployable skills live in `catalog/codex-global/skills/`. Global deployment copies
them to `~/.agents/skills/`; project-scoped skills belong in `<repo>/.agents/skills/`.

Discovery alone is not proof of behavioral compatibility. Do not deploy to a real home until
all static, discovery, behavioral, deployment, and review gates pass. Use explicit temporary
homes and temporary Git repositories for deployment and behavioral tests.

Never deploy credentials, environment files, local settings, generated bytecode, authentication
installers, proxy configuration, or source symlinks. Do not run catalog scripts. Planning and
review are read-only; workspace writes require explicit implementation approval. Agents never
commit: the user reviews and commits manually.
