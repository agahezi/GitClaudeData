# Repository agent instructions

This repository is the single source of every skill used with Claude Code and Codex on any
machine. This file is the instruction authority for all repository work.

- Every skill lives in `skills/<name>/` with a `SKILL.md` whose `name` matches the folder.
  Custom skills are added by hand; downloaded skills are added with
  `python scripts/skills.py add <link>`, which writes an optional `.skill.json` (source, version,
  target tools). Never hand-edit a downloaded skill's recorded version.
- `scripts/skills.py install` installs to `~/.agents/skills/` (Codex) and `~/.claude/skills/`
  (Claude Code), and installs Claude Code plugins listed in `plugins.json`.
- Tests must use temporary homes and temporary Git repositories. Never run `install` or `update`
  against the real home during development.
- Never add credentials, environment files, local settings, generated bytecode, or symlinks to
  `skills/`.
- Planning and review are read-only; workspace writes require explicit implementation approval.
  Agents never commit: the user reviews and commits manually.

Run the tests with `python -m unittest discover -s tests -p "test_*.py"`.
