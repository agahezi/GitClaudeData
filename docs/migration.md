# Migration to a Codex-only repository

The active tree now supports OpenAI Codex only. Canonical workflow skills moved from the former
shared catalog to `catalog/codex-global/skills/`, and `AGENTS.md` replaced CLAUDE.md-style
instruction assumptions.

Repository-managed Claude-only assets were deleted: the Claude global catalog, authentication
token manager and OAuth references, proxy setup command, `qa_tester` agent, legacy workflow,
stream formatter, legacy deploy shell script, mappings, and tests. Git history is the archive for
those removed assets; no dead in-tree archive is retained.

This migration does not inspect, copy, alter, or delete installed `~/.claude` state. It also does
not deploy to `~/.agents` during validation. Real-home deployment remains forbidden until all
compatibility gates pass and the user separately reviews the diff.

No credentials, `.env` files, generated bytecode, local settings, OAuth installers, proxy
configuration, or source symlinks are deployable.
